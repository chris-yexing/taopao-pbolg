> 场景：主路由负责拨号，副路由通过**无线回程**扩展覆盖，两台同 SSID / 同密码做漫游。全程 LuCI 网页操作，不需要命令行。文中「B 房」指副路由所在的房间。

| 项目 | 内容 |
|---|---|
| 目标 | N60 Pro（主路由）+ 红米 AX6（无线回程 AP），同 SSID / 同密码，5 GHz 走 4×4 80 MHz，开启 802.11k/v/r 漫游 |
| 固件 | 两台均为 ImmortalWrt 25.12.2 |
| 操作方式 | 全程 LuCI 网页，不需要命令行 |
| 加密 | 先用 WPA2-PSK 跑通，WPA3 作为可选的第 7 步单独升级 |

## 一、开始之前：三件必须先知道的事

**一、全程用网线操作电脑。**
换软件包、改无线、保存并应用，都会让 Wi-Fi 断开几十秒。如果你是通过 Wi-Fi 连到路由器上改这些，会把自己关在门外，只能按 reset。所以配置期间电脑必须插网线。

**二、这份教程里有一个未经验证的赌注。**
AX6 用的是高通 ath11k 驱动，N60 Pro 用的是联发科 mt76 驱动。**这两个驱动之间做 WDS 无线桥接，我没有找到任何实测报告**，官方文档站被反爬拦住也没核到驱动能力清单。第 4 步就是验证这一把赌注的门禁——**那一步不通就停下来，不要继续往下配**。不通的退路见附录 A。

**三、一次只改一个变量。**
你同时在引入三件新东西：无线回程、KVR 漫游、（可选的）WPA3。任何一件出问题都会表现为"网断了"或"漫游不切"。所以本教程刻意把它们分成独立步骤，每步都有验证点。**验证没过就不要进下一步**，否则出问题时分不清是哪一层的锅。

## 二、原理速查：为什么是这几层

很多人以为"把两台路由器的 SSID 和密码设成一样就叫漫游"，这是不够的。实际上有三层互相独立的配置：

| 层 | 解决什么 | 关键设置 | 不做的后果 |
|---|---|---|---|
| **回程层** | AX6 自己怎么拿到网络 | WDS 模式，两端同信道同频宽 | AX6 根本没网，放出来的 Wi-Fi 是空的 |
| **AP 层** | 手机认不认这是同一个网 | SSID / 密码 / 加密方式完全一致 | 手机看成两个不同的网，要手动切 |
| **KVR 层** | 手机什么时候切、切得快不快 | 802.11r/k/v + Mobility Domain 一致 + wpad 完整版 | 手机赖在原来那台不走，或者切换时断 1–3 秒 |

SSID 和密码一致只解决了第二层。第一层和第三层默认都是关的。

**另外两个容易误解的点：**

- **网页里没有"4×4"这个开关。** 流数由硬件和板级文件决定。AX6 的 5 GHz 在 80 MHz 下本来就是 4 流，2 流只发生在 160 MHz。所以"设成 4×4 80 MHz"实际就是选 80 MHz 频宽，然后去验收时确认流数真的是 4。
- **4×4@80 MHz 和 2×2@160 MHz 一样快。** 两者标称都是 2402 Mbps。选 80 MHz 的理由不是速率，而是：可用信道多、不碰 DFS 雷达、同样功率摊到一半带宽上信号更扎实、在中国不依赖 ImmortalWrt 的 CN 管制域补丁。

## 三、第 0 步：记录现状并搬机器

**目的**：后面每一步都要用到这些信息，先记下来免得中途去翻。同时把 AX6 临时接成能上网的状态，因为第 1 步要下载软件包。

**操作**：

1. 登录 N60 Pro 的网页，进 **网络 → 接口**，记下 LAN 的 IPv4 地址。本教程假设是 `192.168.1.1`，**如果你的不是，后面所有出现这个地址的地方都要换成你的**。
2. 进 **网络 → 无线**，记下哪个 radio 是 5 GHz、哪个是 2.4 GHz（页面上会标频段），以及当前 SSID 和密码。
3. 进 **系统 → 软件包**，筛选 `wpad`，记下已安装的包全名（可能是 `wpad-basic-mbedtls`、`wpad-basic-wolfssl` 或别的）。
4. 把 AX6 搬到 B 房，**用网线把 AX6 的 WAN 口接到 N60 Pro 的 LAN 口**（这是临时的，第 3 步会撤掉），电脑用网线接 AX6 的 LAN 口。此时 AX6 是普通二级路由，能上网。
5. 在 AX6 上重复第 3 小步，记下它的 wpad 包名。

**填写表**：

| 项目 | 你的值 |
|---|---|
| N60 Pro LAN 地址 | ______________ |
| N60 Pro 5 GHz radio 编号 | ______________ |
| N60 Pro 2.4 GHz radio 编号 | ______________ |
| SSID | ______________ |
| Wi-Fi 密码 | ______________ |
| N60 Pro 的 wpad 包名 | ______________ |
| AX6 的 wpad 包名 | ______________ |

**验证**：电脑能打开 AX6 的网页，也能打开外网。

## 四、第 1 步：两台都换成完整版 wpad

**目的**：补齐 802.11v。

**为什么要换——这里有个流传很广的错误说法需要澄清**：网上大量教程写"wpad-basic 不支持 802.11r，所以必须换"。**这是错的。** v25.12.2 的 hostapd 包描述原文是：

> "This package contains a basic IEEE 802.1x/WPA Authenticator and Supplicant with WPA-PSK, SAE (WPA3-Personal), 802.11r and 802.11w support."

basic 本来就带 802.11r 和 802.11w，甚至带 WPA3。**真正缺的是 802.11v（WNM / BSS Transition）**，也就是 KVR 里的 V。它的作用是**让 AP 主动告诉手机"隔壁那台信号更好，你切过去"**。少了它，漫游全靠手机自己判断，而手机粘性普遍很强，经常信号已经很差了还赖在原来那台上——这正是"同名 Wi-Fi 但走到另一头还是卡"的典型原因。

`wpad-openssl` 是完整版，11r / 11k / 11v 全有，**而且本身就编译了 802.11s mesh**，所以万一后面要改用 mesh 回程，不用再换包。

**操作**（两台各做一遍）：

1. 进 **系统 → 软件包**（System → Software）。
2. 点 **「更新列表」**(Update lists)，等它跑完。
3. 筛选框输入 `wpad`，在**已安装**列表里找到第 0 步记下的那个 basic 包，点 **「移除」**。
4. 再筛选 `wpad-openssl`，在可用列表里点 **「安装」**。

**注意**：

- **必须先移除再安装。** 两个包提供同一个可执行文件，顺序反了会报文件冲突。
- 移除到安装之间 Wi-Fi 是断的，**这就是为什么必须有线操作**。
- N60 Pro 上做这一步时，B 房全家会断网几分钟，挑个合适时间。
- 如果移除时报依赖冲突、或者安装失败，**把报错原文记下来，不要硬点**，见附录 A。

**验证**：软件包页面已安装列表里出现 `wpad-openssl`，且 basic 那个不见了。两台都要确认。

## 五、第 2 步：配置 N60 Pro 的无线

**目的**：把主路由的 5 GHz 设成 WDS 接入点（等 AX6 来连），固定信道和频宽，并打开 KVR。2.4 GHz 同步打开 KVR。

### 2.1 设 5 GHz 的频率

进 **网络 → 无线**，找到 5 GHz 那个 radio，点 **「编辑」**。

在 **「常规设置」** 标签页里：

| 字段 | 填什么 | 为什么 |
|---|---|---|
| 工作频率 → 模式 | **AX**（802.11ax） | 用 Wi-Fi 6 的高阶调制 |
| 工作频率 → 信道 | **149** | 5.8 GHz 段功率上限更高、不碰 DFS 雷达。**如果下拉里没有 149，就选 36，后面 AX6 必须跟着选同一个** |
| 工作频率 → 频宽 | **80 MHz** | AX6 的 5 GHz 在 80 MHz 下是 4 流；160 MHz 会掉到 2 流，标称速率一样但信道更少、更容易撞雷达 |
| 国家代码 | **CN** | 管制域决定哪些信道和功率可用，两台必须一致 |

点「保存」。

### 2.2 设 5 GHz 的 AP 接口

在这个 radio 下面的接口列表里，点那个 AP 接口的 **「编辑」**。

**「常规设置」标签页**：

- **模式**下拉选 **「接入点 (WDS)」/ Access Point (WDS)**
  → 这是 WDS 的服务端。普通"接入点"模式不接受四地址帧，AX6 就连不上。
- **ESSID** 保持你现在的名字不动
- **网络** 确认勾的是 `lan`

**「无线安全」标签页**：

- **加密**选 **WPA2-PSK**
  → 为什么不用 WPA3：见第 7 步。WPA3 强制 PMF，而本教程用的「本地生成 PMK」对 WPA3 的 SAE 不成立，会直接破坏漫游。
- 密码保持不动

**「WLAN 漫游」标签页**（25.12 的 LuCI 把 11r/k/v 集中到了这一个页面）：

| 选项 | 设成 | 为什么 |
|---|---|---|
| **802.11r**（快速切换） | **勾选** | 让手机切换时复用已派生的密钥，省掉重新完整认证，切换从秒级降到毫秒级 |
| Mobility Domain | `a1b2` | 4 位十六进制，**两台必须完全一样**。它标识"这几台 AP 属于同一个漫游域"。你自己定一个值也行，但要记住 |
| FT 协议 | **FT-PSK** | 对应 WPA2-PSK 的快速切换方式 |
| **本地生成 PMK**（Generate PMK locally） | **勾选** | 让每台 AP 用 SSID+密码自己算出漫游密钥，**免去两台之间手工交换密钥列表**。这是本教程能简化的关键 |
| **FT over DS** | **不勾** | 走无线直接切换，不经过有线分发系统绕一圈 |
| **802.11k** | **勾选** | AP 给手机提供邻居 AP 列表，手机不用全信道扫描就能知道该往哪切 |
| **802.11v / BSS Transition** | **勾选** | AP 主动建议手机切到更好的那台。**这就是第 1 步换包要补的能力** |

点 **「保存并应用」**。

### 2.3 设 2.4 GHz

同样进 2.4 GHz radio 的「编辑」：

- 信道 **1**，频宽 **20 MHz**
  → 2.4 GHz 不承担回程，所以**可以和 AX6 错开信道**，减少干扰。20 MHz 在拥挤的 2.4 GHz 段比 40 MHz 稳。
- 模式保持普通 **「接入点」**（不用 WDS）
- 进它的 AP 接口，把 **「WLAN 漫游」标签页按 2.2 的表格一模一样设一遍**，**Mobility Domain 填同一个值**
- 加密同样 WPA2-PSK，SSID 和密码与 5 GHz 一致

点「保存并应用」。

**验证**：手机能正常连上 N60 Pro 的 Wi-Fi 并上网。此时漫游还看不出效果（只有一台），正常。

## 六、第 3 步：把 AX6 改成纯二层 AP

**目的**：让 AX6 不再是一台独立路由器，而变成"无线交换机"。这样所有设备的流量都落在主路由上，**主路由上运行的任何插件对连到 AX6 的设备照样生效**。

**为什么必须是二层**：WDS 本身就是二层桥接。如果 AX6 还开着 DHCP 和 NAT，就变成双层 NAT，设备拿到的网关是 AX6 而不是主路由，主路由上的插件就拦不到这些流量了。

### 3.1 撤掉临时网线

**把 AX6 WAN 口上那根接 N60 Pro 的网线拔掉。** 后面不再需要它。

### 3.2 改 LAN 地址并关掉 DHCP

电脑仍插在 AX6 的 LAN 口上，登录 AX6 网页，进 **网络 → 接口 → LAN → 编辑**：

| 字段 | 填什么 | 为什么 |
|---|---|---|
| 协议 | **静态地址** | 不再自动获取，地址固定下来方便管理 |
| IPv4 地址 | `192.168.1.2` | 与 N60 Pro 同网段但不冲突。**如果第 0 步记下的不是 192.168.1.1，这里要跟着改成同网段的另一个地址** |
| IPv4 子网掩码 | `255.255.255.0` | 同网段 |
| IPv4 网关 | `192.168.1.1` | 指向 N60 Pro |
| DNS 服务器 | `192.168.1.1` | 指向 N60 Pro |

同一页往下找到 **「DHCP 服务器」** 区块，勾上 **「忽略此接口」**(Ignore interface)。
→ AX6 不再发 IP，全网只有 N60 Pro 一个 DHCP 服务器，避免两台抢着分配。

点「保存并应用」。

### 3.3 禁用不需要的服务

- **网络 → 接口 → WAN**，点 **「禁用」**
- **系统 → 启动项**（System → Startup），在列表里找到 `dnsmasq`、`odhcpd`、`firewall`，**各点一次「禁用」**
  → 分别是 DHCP/DNS、IPv6 分配、防火墙+NAT。纯二层 AP 这三个都不需要，留着反而可能干扰。

### 3.4 电脑手动设静态 IP（这一步不做会失联）

**为什么**：AX6 刚刚关掉了 DHCP，而无线回程还没建立，所以电脑此刻**没有任何途径自动拿到 IP**，会打不开 AX6 的网页。必须手动设一个。

Windows 图形界面操作：

1. **设置 → 网络和 Internet → 以太网**
2. 找到 **「IP 分配」**，点旁边的 **「编辑」**
3. 下拉选 **「手动」**，打开 **IPv4** 开关
4. 填：
   - IP 地址 `192.168.1.10`
   - 子网掩码 `255.255.255.0`
   - 网关 `192.168.1.1`
   - 首选 DNS `192.168.1.1`
5. 保存

**验证**：浏览器打开 `192.168.1.2`，能进 AX6 的网页。
**注意地址变了**——旧的 `192.168.1.1` 现在指向 N60 Pro（而且此刻还不可达，因为回程没建）。此时电脑能管理 AX6，但**还不能上网**，这是正常的。

## 七、第 4 步：建立 AX6 的无线回程 ⚠️ 门禁步骤

**目的**：让 AX6 通过无线连上 N60 Pro，拿到网络。这是整个方案唯一未经验证的环节。

**操作**：

1. 在 AX6 网页上进 **网络 → 无线**，在 **5 GHz** 那个 radio 上点 **「扫描」**(Scan)。
2. 列表里找到 N60 Pro 的 SSID，点 **「加入网络」**(Join Network)。
3. 弹窗里：
   - **WPA 密码**填你的 Wi-Fi 密码
   - **「新网络的名称」这一栏填 `lan`** ← **最关键的一步**。默认它会新建一个叫 `wwan` 的独立网络，那样 AX6 就变成二级路由、双层 NAT，主路由上的插件全部失效。填 `lan` 才能桥接进现有网络
   - **防火墙区域**选 `lan`
4. 点「保存并应用」。
5. 回到 **网络 → 无线**，点刚建出来的那个 Client 接口的 **「编辑」**：
   - **「常规设置」→ 模式** 改成 **「客户端 (WDS)」/ Client (WDS)**
     → 普通"客户端"模式用的是三地址帧，桥接过去的设备 MAC 会被改写，二层不通。WDS 客户端用四地址帧，才是真正的透明桥接
   - 确认 **「网络」** 勾的是 `lan`（如果第 3 小步没生效，在这里手动改成 lan）
   - **「无线安全」** 确认是 WPA2-PSK + 正确密码
   - **不要在 Client 接口上开 WLAN 漫游**，那是给 AP 接口用的
6. 点「保存并应用」。

**验证（三项都要过）**：

1. **网络 → 无线** 页面上，这个 Client 接口显示**已连接**，有信号强度和对端 BSSID。
2. 电脑（仍是手动 IP `192.168.1.10`）能打开 `192.168.1.1`，也就是 N60 Pro 的网页。
3. 电脑能上网。

**如果不通**：

- 先检查两台的 5 GHz **信道和频宽是不是完全一致**（必须都是 149 + 80 MHz，或都是 36 + 80 MHz）。无线回程两端不在同一信道上根本关联不上——**这和"两台 AP 信道要错开"的常识相反**，那条常识只适用于有线回程。
- 再检查 N60 Pro 的 AP 模式是不是真的选了「接入点 (WDS)」，AX6 是不是「客户端 (WDS)」。
- 都对还是不通，**就是跨驱动 WDS 没成**。停在这里，看附录 A 的退路，把页面截图和现象记下来。

**通了之后**：把电脑的 IP 设置改回 **「自动 (DHCP)」**，让它从 N60 Pro 拿地址。

## 八、第 5 步：AX6 放出同名 Wi-Fi 并开 KVR

**目的**：让 AX6 成为第二台 AP，手机可以在两台之间漫游。

**前提**：第 4 步三项验证全部通过。

### 5.1 加 5 GHz 的 AP 接口

**网络 → 无线**，在 5 GHz radio 上点 **「添加」**(Add)：

- **「常规设置」**：
  - 模式选普通 **「接入点」**（不是 WDS——这个接口是给手机连的，不是给回程用的）
  - **ESSID 填和 N60 Pro 完全一样的名字**，一个字符都不能差
  - **「网络」勾 `lan`**
- **「无线安全」**：**WPA2-PSK**，密码和 N60 Pro 完全一样
- **「WLAN 漫游」**：按第 2.2 步的表格**逐项设成一样**，**Mobility Domain 必须是同一个值**

点「保存并应用」。

### 5.2 设 2.4 GHz

进 AX6 的 2.4 GHz radio「编辑」：

- 信道 **11**，频宽 **20 MHz**
  → 与 N60 Pro 的 1 错开。2.4 GHz 不承担回程，可以错开
- 进它的 AP 接口：ESSID 同名、密码同、WPA2-PSK、**「WLAN 漫游」同样设一遍，Mobility Domain 一致**

点「保存并应用」。

**验证**：手机能连上 Wi-Fi 并正常上网。走到 AX6 附近时，看它是不是切过去了（下一节讲怎么看）。

## 九、第 6 步：验收

**目的**：确认三件事——流数真的是 4、漫游真的在切、切换真的不断线。

### 6.1 确认流数（4×4 有没有生效）

在 **网络 → 无线** 页面，每个接口下方有 **「已连接的工作站」**(Associated Stations) 表格。看 **RX / TX 速率**那一列：

- 如果它显示完整速率串，里面会写 **`HE-NSS 4`** 或 `HE-NSS 2`——**这就是流数，4 才是你要的 4×4**
- 如果只显示一个数字，那流数在网页里看不到，只能靠测速间接判断

**预期吞吐（推算量级，不是实测）**：2402 Mbps 的标称 PHY，直连 iperf3 大约 650–820 Mbps；但 AX6 的 5 GHz 单 radio 同时做回程和 AP 是**半双工共享 airtime**，中转后客户端大约 **300–450 Mbps**。千兆宽带拿不满，这是无线回程的固有代价，不是配置问题。

### 6.2 确认漫游在切

手机连着 Wi-Fi，从 N60 Pro 附近走到 AX6 附近。在**两台**的「已连接的工作站」表格里看手机的 MAC 地址出现在哪一台。

- 切过去了 → 漫游在工作
- 一直赖在原来那台不走 → 802.11k/v 没生效，或者手机粘性太强。先确认两台的 Mobility Domain 真的一样、wpad 真的换成了 openssl

### 6.3 确认切换不断线

网页里没有 ping 工具。手机上装一个 ping App，持续 ping `192.168.1.1`，然后走动：

- **几乎不丢包** → 802.11r 生效
- **丢 1–3 个** → 只是手机自己在漫游，11r 没起作用

### 6.4 稳定性观察

AX6 是 512 MB 内存 + ath11k 驱动，[openwrt#24154](https://github.com/openwrt/openwrt/issues/24154) 的内存耗尽问题还在。跑几天，留意有没有无故重启或 Wi-Fi 消失。网页上 **状态 → 系统日志** 可以看有没有异常。

## 十、第 7 步（可选，建议以后再做）：升级 WPA3

**为什么现在不做**：

1. **和本教程的漫游配置直接冲突。** WPA3 强制启用 PMF（802.11w），而第 2 步勾的 **「本地生成 PMK」对 WPA3 的 SAE 不成立**——SAE 的 PMK 没法在每台 AP 上本地算出来，必须靠 R0KH / R1KH 密钥列表在两台之间交换。见 [openwrt#9181](https://github.com/openwrt/openwrt/issues/9181)，原话是 "WPA3 does not work with 'Generate PMK locally'... Turn it off, and it should work."。关掉它就得手工在两台填 MAC / ID / 密钥一一对应的列表，配置量翻几倍，填错一个字符就是漫游失败。
2. **该 issue 已被一个"修复 mt7996 上 FT-SAE"的提交关闭**（据页面记录是 2026 年 6 月），**但那个修复是否覆盖 mt76 和 ath11k、是否进了 25.12.2，未核实**。所以不能当"已经没问题了"。
3. **兼容性代价**：WPA3 强制 PMF，家里的智能插座、摄像头、扫地机、老手机、打印机很可能直接连不上。
4. **排错维度**：现在已经在赌跨驱动 WDS 和 KVR 两件事，再叠 WPA3 会让问题定位变成三维。

**建议时机**：第 6 步全部通过、稳定跑一两周之后，**单独改加密这一项**，改完立刻重测漫游。一次只动一个变量。

**届时需要补的核实**：那个 FT-SAE 修复的提交有没有进 25.12.2；以及 R0KH / R1KH 在网页里的填法。这两项现在都没做。

**顺便纠正一个叫法**：没有"psk3"。WPA3 个人版叫 **SAE**，LuCI 加密下拉里显示为 **WPA3-SAE**，另有 WPA2/WPA3 混合过渡模式。

## 十二、附录 B：未验证项与已知风险（审核时重点看这里）

**未验证，需要实测才知道：**

1. **ath11k ↔ mt76 的跨驱动 WDS 能不能通** —— 全教程最大的赌注，第 4 步是门禁。没有任何实测报告，官方文档站被反爬拦住。
2. **AX6 在客户端模式下能不能真的跑 4 流** —— 硬件规格是 4×4@80 MHz，但驱动/板级文件在 STA 模式下是否放开 4 流，未核实。第 6.1 步验。
3. **802.11s 备选路径同样未验证** —— 附录 A 的退路①不是保底方案，是另一个赌注。
4. **FT-SAE 修复是否进 25.12.2** —— 影响第 7 步，现在未核。
5. **网页里「已连接的工作站」是否显示完整速率串** —— 影响 6.1 能不能看到流数，不同 LuCI 版本渲染可能不同。

**已知风险：**

- **5 GHz 两台必须同信道**，覆盖重叠区会互相竞争 airtime。这是无线回程的固有代价，配置消不掉。
- **单 radio 回程 + AP 半双工**，中转吞吐约减半。
- **ath11k 512 MB 内存耗尽**（[openwrt#24154](https://github.com/openwrt/openwrt/issues/24154)）。
- **换 wpad 会断 Wi-Fi**，N60 Pro 上做的时候全家断网几分钟。
- **改 LAN 地址后浏览器地址要跟着换**，第 3.4 步的手动 IP 不做会失联。

**已核实的事实（可放心引用）：**

- `wpad-basic-*` 的包描述含 WPA-PSK、SAE(WPA3)、802.11r、802.11w；**缺 802.11v (WNM/BSS Transition)**。来源：v25.12.2 hostapd Makefile 包描述原文 + [unifi-openwrt-roaming 项目说明](https://github.com/d-malinowski/unifi-openwrt-roaming)。
- `wpad-openssl` 是完整版，**自带 802.11s mesh**，不需要 `wpad-mesh-openssl`。
- LuCI 25.12 的无线接口编辑页有独立的 **「WLAN 漫游」(WLAN roaming)** 标签页，11r/k/v 都在里面；WDS 是**模式下拉选项**（接入点 (WDS) / 客户端 (WDS)），不是隐藏开关。来源：LuCI openwrt-25.12 分支 wireless.js。
- N60 Pro 的 5 GHz 是 **MT7975PN，4×4 MIMO @160 MHz**，所以两端都 4 流，4×4↔4×4 物理上成立。
- 4×4@80 MHz 与 2×2@160 MHz 的 HE MCS11 标称 PHY **同为 2402 Mbps**。
- 中国 160 MHz 可用依赖 ImmortalWrt 的 `600-custom-change-txpower-and-dfs.patch`（把 5150–5350 合成 160 MHz、30 dBm、去掉 NO-OUTDOOR 和 DFS，**仅改 CN**）；80 MHz 不依赖它。
- WDS / 纯 802.11s 可用，**batman-adv 在 24.10.0+ 会把 TX 打到 2–3 Mbps**（[openwrt#18703](https://github.com/openwrt/openwrt/issues/18703)），所以本教程不用 batman-adv。

## 十三、附录 C：本教程修正过的三个错误说法

审核时如果看到别处教程和这里不一致，以这里为准：

1. **"wpad-basic 不支持 802.11r"** —— 错。basic 带 11r 和 11w，缺的是 11v。换包的真实理由是补 11v。
2. **"mesh 需要 wpad-mesh-openssl，和 KVR 的 wpad-openssl 互斥"** —— 错。完整版 wpad-openssl 自带 mesh，一个包全覆盖。mesh 专用变体反而是精简版（只有 mesh + SAE，没有 11r/11v）。
3. **"两台 AP 的信道要错开"** —— 只适用于**有线回程**。无线回程两端必须同信道，否则关联不上。本教程 5 GHz 同信道、2.4 GHz 错开。
