## Context

该变更旨在为博客添加一篇关于现金流指数深度分析的投资类文章。博客使用 Hugo 静态站点生成器，PaperMod 主题，通过 GitHub Pages 部署。所有内容为中文纯静态内容，无需后端或外部 API。

## Goals / Non-Goals

**Goals:**
- 创建一篇关于三个可投资现金流指数（沪深300自由现金流指数932366、国证自由现金流指数399351、中证500自由现金流指数932367）的专业分析文章
- 对每个指数的规则和选股逻辑进行深度解析
- 提供基于研究的个人投资见解和价值判断
- 将复杂的金融信息降维为易懂的内容

**Non-Goals:**
- 不涉及技术代码变更
- 不修改现有系统功能
- 不创建新的模板或主题组件

## Decisions

### 内容结构设计
采用从宏观到微观的结构：
1. 引言部分说明现金流投资的背景和重要性
2. 逐一对三个指数进行规则和逻辑分析
3. 对比分析和投资见解
4. 实用建议部分

**理由：** 这种结构符合读者认知习惯，从基础概念到具体分析再到实际应用，逻辑清晰。

### 信息降维方法
采用以下技术手段：
- 使用生动的比喻解释复杂概念
- 结合具体数据和案例
- 用列表和表格对比不同指数
- 避免过于技术性的术语，或加以解释

**理由：** 降低理解门槛，让非专业投资者也能理解核心概念。

### 数据来源
主要参考官方指数编制规则文件、券商研究报告和权威金融数据提供商的信息。

**理由：** 确保分析的准确性和权威性，避免基于错误或过时数据得出结论。

### 风险提示策略
在提供个人见解时，明确标注主观判断部分，并在文末添加标准化风险提示。

**理由：** 区分事实与观点，提醒读者投资风险，符合内容责任要求。

## Risks / Trade-offs

**风险：** 分析内容可能随市场环境变化而过时
**缓解措施：** 在文中注明分析时间节点，建议读者参考最新官方规则

**风险：** 个人见解存在局限性
**缓解措施：** 明确标注为主观分析，提示投资者结合自身情况决策

**权衡：** 深度分析与可读性的平衡
**决策：** 优先保证核心概念的准确传达，部分技术细节可省略或简化
