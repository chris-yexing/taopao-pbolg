## ADDED Requirements

### Requirement: 现金流指数分析文章创建
系统 MUST 生成一篇关于现金流指数的深度分析文章，该文章 MUST 包含对沪深300自由现金流指数（932366）、国证自由现金流指数（399351）、中证500自由现金流指数（932367）三个指数的规则和选股逻辑的详细分析以及个人投资见解。

#### Scenario: 创建现金流指数分析文章
- **WHEN** 系统生成现金流指数分析文章
- **THEN** 文章 MUST 包含三个指数的规则分析、选股逻辑解析和个人投资见解内容

### Requirement: 指数规则研究
系统 MUST 详细研究和分析每个指数的编制规则、计算方法、成分股选择标准等技术性规则。

#### Scenario: 解析指数规则
- **WHEN** 分析指数规则时
- **THEN** 系统 MUST 收集并整理包括指数代码、编制机构、基期基点、指数计算方法、调整频率等完整规则信息

### Requirement: 选股逻辑分析
系统 MUST 深入分析每个指数的选股逻辑，包括样本空间确定、筛选条件、权重分配方法等核心选股策略。

#### Scenario: 分析选股逻辑
- **WHEN** 解析选股逻辑时
- **THEN** 系统 MUST 详细说明每个指数的样本空间定义、选股标准、权重分配规则、调整机制等选股流程

### Requirement: 信息降维
系统 MUST 将复杂的金融和技术信息进行降维处理，用通俗易懂的语言呈现专业内容，降低理解门槛。

#### Scenario: 执行信息降维
- **WHEN** 处理专业金融信息时
- **THEN** 系统 MUST 将复杂的指数规则和选股逻辑转化为简单明了的表达方式，配合实例帮助读者理解

### Requirement: 个人投资见解
系统 MUST 在客观分析基础上，提供基于个人研究的投资见解和价值判断，包括指数优劣对比、适用场景、风险提示等。

#### Scenario: 提供投资见解
- **WHEN** 总结分析结果时
- **THEN** 系统 MUST 包含对不同指数的优劣分析、适用投资人群、风险收益特征以及实际投资建议等个人见解内容
